FAQ

📱 iPhone: I can't find these apps in the App Store
These apps are not on the China App Store, so a China Apple ID won't find them. Two options:
  1. Recommended: create a non-China Apple ID (US or HK region — free, choose "None" for payment), sign into the App Store with it, then search and buy. You can switch back to your own account afterwards; the app keeps working.
  2. Don't want the hassle? Install the free Karing or V2Box — plenty for most users.
🍎 macOS says "is damaged and can't be opened"
The file isn't broken — macOS Gatekeeper is blocking an unsigned app. In Terminal run: 
xattr -cr /Applications/Clash\ Verge.app
(replace with your actual app name), then reopen it.
🪟 Windows Defender / antivirus flags it
These clients modify the system proxy, so they're often false-flagged. Every file here is the original, unmodified release. Where a project publishes a SHA256, it's shown next to the file — match it and you've confirmed the file is clean. Add an exception and install.
🔐 How do I check a file wasn't tampered with?
Some projects (e.g. Clash Party) publish a SHA256, which this page fetches and shows beside the file. To check: 
Windows (PowerShell):  Get-FileHash .\file.exe -Algorithm SHA256
macOS / Linux:         shasum -a 256 filename
If it matches what's shown here, the file is exactly what the project published.
